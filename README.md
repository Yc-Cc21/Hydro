# Hydro 💧

Material Design 3风格的 Android 饮水记录 App。

个人Vibe Coding小项目，不喜勿喷

记录每天喝了多少水，看看自己有没有达到今日目标。

## 功能特性

- 快速记录饮水量
- 自定义每日饮水目标
- 每日零点自动重置
- 撤回上一次饮水记录
- 查看历史饮水记录
- 本地持久化保存数据（离线可用）
- 支持深色模式
